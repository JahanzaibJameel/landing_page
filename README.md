## 📖 About The Project

**3legant** is a static, pixel-perfect HTML/CSS landing page for a gift and decoration store.

It showcases a clean, modern design with:

* Elegant typography and a soft color palette
* Fully responsive layout for desktop, tablet, and mobile
* CSS-only interactive mobile navigation
* Multiple product and category cards
* Feature icons and promotional sections
* Newsletter signup form
* Modern footer with navigation and social icons

This project is ideal for learning **HTML5 and CSS3**, practicing **Flexbox**, **CSS Grid**, **media queries**, and building a professional e-commerce interface from scratch.

> **No JavaScript is used** — all interactions are implemented using pure HTML and CSS.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You only need:

* A modern web browser such as Chrome, Firefox, Safari, or Edge
* A code editor such as VS Code (optional)
* Live Server extension (optional)

### Installation

#### 1. Clone the repository

```bash
git clone https://github.com/JahanzaibJameel/landing_page.git
```

#### 2. Navigate to the project directory

```bash
cd landing_page
```

#### 3. Open the project

Open `index.html` directly in your browser, or use the VS Code Live Server extension.

```bash
# Simply double-click index.html
# Or launch it using Live Server
```

No build tools, package managers, or dependencies are required.

## 🎨 Customization

### Changing Colors

All colors are defined inside the CSS section of `index.html`.

Search for the existing color values and replace them with your preferred brand colors.

Example:

```css
.product-btn-2 {
    background-color: #38cb89;
}
```

### Replacing Images

Replace the existing image files in the project directory with your own images.

You can either:

1. Keep the existing filenames, or
2. Update the corresponding `src` attributes in `index.html`.

Example:

```html
<img src="your-image.png" alt="Product">
```

### Editing Text

All website content is directly inside `index.html`.

Simply search for the text you want to change and replace it with your own content.

## 📱 Responsive Design

The layout is optimized for multiple screen sizes:

### 🖥️ Desktop

* Full multi-column layout
* Complete navigation
* Large hero section
* Product grids
* Full footer layout

### 📱 Tablet — ≤ 768px

* Responsive stacked sections
* Mobile navigation
* Adjusted product grids
* Optimized spacing and typography

### 📱 Mobile — ≤ 540px

* Single-column layout
* Compact cards
* Smaller typography
* Mobile-friendly navigation
* Optimized spacing

The interface is designed to provide a consistent experience across desktop, tablet, and mobile devices.
